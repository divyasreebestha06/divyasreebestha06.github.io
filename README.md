## 🎨 Key Features & Highlights

- **Dynamic Hero Section:** Ambient glowing radial orbs, interactive live status indicator (*"Available for Software Engineer Intern Roles"*), and quick-action metrics strip.
- **Interactive Particle Constellation:** Custom HTML5 canvas physics engine (`ParticleBackground.jsx`) with smooth mouse gravitational repulsion and node connection lines.
- **34 Verified Codebases Showcase:** Complete catalog of 34 GitHub repositories categorized across AI/ML, Backend Microservices, Distributed Systems, Java/Spring Boot, and Full-Stack Web.
- **Deep-Dive Case Study Modal:** Every project features an interactive architectural modal breaking down the *Problem Context*, *System Architecture*, *Key Technical Challenges*, and *Performance Impact*.
- **Live Search & Domain Filters:** Real-time search by keyword (e.g. `Python`, `Docker`, `FastAPI`, `Java`, `AST`) and interactive category filter chips with live counts.
- **1-Page ATS-Optimized Resume:** Built-in downloadable vector PDF resume (`Divya_Sree_Bestha_Resume.pdf`) strictly calibrated to a single page.
- **Dark / Light Mode Engine:** Seamless theme switching with persistent state saved in `localStorage`.
- **Contact Dispatch Hub:** Direct email 1-click clipboard utility, form validation, and mail client integration.

## 🚀 Running Locally

To run this portfolio on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/divyasreebestha06/divyasreebestha06.github.io.git
   cd divyasreebestha06.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
